# Neon's Macro V2 (ASTD)

**by NeonLeedz** - a macro for the Roblox game **All Star Tower Defense**.

## Download

1. Open **[Releases](https://github.com/NeonLeedz/ASTD-Macro-Releases/releases/latest)** and download **Neon's Macro V2.zip** from the newest version.
2. Unzip it anywhere (for example your Desktop).
3. Double-click **Neon's Macro V2.exe**. Nothing else to install.

Already have it? Click **⟳ Check for updates** at the top of the macro. Your settings, loadouts and backgrounds are kept.

## What it does on your PC

* Looks at the Roblox window (screenshots) to read the wave counter and find buttons.
* Clicks and presses keys in Roblox for you, and snaps the Roblox window into its own window.
* Keeps everything (settings, loadouts, recordings) in its own folder next to the .exe.

## What it never does

* Never asks for or reads your Roblox or Discord password or account.
* Never sends anything anywhere unless you set it up yourself:
  * **Discord webhook** - only to the webhook link *you* paste in (game results + a screenshot of Roblox).
  * **Check for updates** - only talks to this GitHub page, and only when you click it.
  * **Rejoin** - only opens the Roblox private server link *you* paste in.
* Doesn't install anything and stops completely when you close it.

## Antivirus warning?

Some antivirus programs flag new .exe files made from Python as "unknown". That's a false alarm. Only download the macro from this page - never from re-uploads.
